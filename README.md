# Conference Registration Web Application

Учебное веб-приложение на Django для регистрации участников конференции.

## Цель

На практике изучить разработку веб-приложений на Django: создание проекта и приложения, маршрутизацию, представления, шаблоны, модели и работу с базой данных SQLite.

## Что реализовано

* создан Django-проект и отдельное приложение `regform`;
* настроена маршрутизация страниц;
* реализованы представления для главной страницы, информационной страницы и страницы регистрации;
* создана модель `User` для хранения данных участника;
* создана миграция базы данных;
* используется SQLite;
* создан HTML-шаблон формы регистрации;
* секретный ключ Django передаётся через переменную окружения.

## Форма регистрации

В шаблоне предусмотрены поля:

* имя;
* фамилия;
* отчество;
* email;
* дата рождения;
* секция конференции.

Форма реализована как учебный интерфейс и демонстрирует создание HTML-формы в Django.
